# TITULO  
*A digital platform specializing in providing accurate land surveys and secure documentation services*

## 🚀 Project Overview  
TITULO is a web‐based platform developed using **PHP** and **MySQL**, intended to streamline land‐survey and documentation workflows.  
- Clients can upload files online instead of going to the office.  
- Admins can review, approve, or reject submissions.  
- Secure documentation and workflows reduce physical handling and increase efficiency.  

## 🧩 Features  
- 📂 **File Upload for Clients** — Clients can submit required land survey or documentation files online.  
- ✅ **Admin Approval Workflow** — Admins review uploads, approve or reject, and leave comments.  
- 📊 **Request Tracking** — Clients can track the status of their submissions, similar to order tracking in e-commerce platforms.  
- 💬 **Client-Admin Chat** — Real-time messaging allows clients and admins to communicate directly within the platform.  
- 👥 **Role-Based Access** — Separate client and admin roles with appropriate permissions.  
- 🗂 **Dashboard & Notifications** — Both clients and admins get an overview of pending, approved, or rejected requests.  
- 🔒 **Secure Documentation** — All sensitive files and messages are stored safely in the MySQL database.
